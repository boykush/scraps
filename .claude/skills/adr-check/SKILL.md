# ルールとの照合

[boykush/adr](https://github.com/boykush/adr) のルールは、各リポジトリの作業が守ること。ルールを実行する仕組みは無く、変更を読んでルールに照らす。

照合は作業を終えてから行う。作業の前や途中に読むと、作業が触れないルールまでセッションに載ってノイズになる。違反を指摘されて直すときは、指摘されたルールを読んで直す。

## 照合する

1. `list_rules` でルールを読む。返るのは accepted の決定のルールだけ
2. 文法は skill `ade-rule-dsl` の reference で確かめる。記憶や似た DSL から推し量らない
3. ルールは、それを読んだセッションが作業しているリポジトリについての言明。パスはそのリポジトリの root から当てる
4. 変更が、ルールの禁じるものを足していないか、触ったファイルに残していないか、ルールの求めるものを欠いていないかを見る
5. ルールが当てはまるかを決めるのに理由が要るときだけ、`get_decision` で決定を読む。id が分からなければ `list_decisions` で探す。決定のうちルールに書かれていない部分は、作業を縛らない

## 違反があったら

- 作業を直して、ルールを満たす
- ルールを破らないと作業が成り立たないように見えたら、破らずにユーザーへ伝える。ルールを変えるのは boykush/adr で、作業しているリポジトリではない
- ルールはリポジトリ自身の慣習として扱う。コードのコメントにも commit message にも PR にも、ルールの元になった決定を名指ししない
