#[[Notation/Markdown]]

Scraps compiles standard Markdown plus
[[Reference/Wiki-link Notation]]. Authoring stays close to plain Markdown
so files render correctly in any viewer; the typed `[[…]]` overlay adds
compiler-enforced cross-references on top.
